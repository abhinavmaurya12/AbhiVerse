## ✨ About the Project

AbhiVerse is designed to be the central destination for my digital presence. Instead of sharing multiple links separately, I can showcase my websites, projects, and professional profiles from one place.

Whether you're exploring my portfolio, checking out a website replica, or discovering my Java learning platforms, AbhiVerse makes everything accessible in just a few clicks.

## 🚀 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/abhinavmaurya12/AbhiVerse.git
```

**2. Open the project folder**

```bash
cd AbhiVerse
```

**3. Launch the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
